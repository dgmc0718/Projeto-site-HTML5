# Botafogo Fan Site
- A proposta desse html, é fazer um protótipo simples de um site de fan feito para os torcedos do clube de futebol Botafogo, do Rio de Janeiro
- Ele utiliza divisão de pastas para separar os arquivos html, as imagens, áudio e vídeo utilizado
- Além disso, tenta fazer uso geral no projeto inteiro das tags de HTML5 que se mostrem compatíveis e necessárias à idéia do site
- As páginas do site tentam trazer de maneira geral, um aspecto informativo ao usuário, e a experiência do uso se baseia principalmente nesse aspecto de conhecimento a respeito do clube
